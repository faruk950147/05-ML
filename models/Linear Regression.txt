# Beginner Level

# 2. What is Regression?

Regression is a **Supervised Machine Learning technique** used to predict a **continuous numerical value**.

Examples:

• House Price Prediction
• Salary Prediction
• Temperature Prediction
• Sales Prediction
• Student Marks Prediction
• Car Price Prediction

Example:

```text
Area → House Price

1000 sq ft → 200000
1500 sq ft → 300000
2000 sq ft → 400000
```

Here:

```text
Input  = Area
Output = Price
```

Because Price is a continuous numerical value, this is a Regression problem.

# 3. What is Linear Regression?

Linear Regression finds a **linear relationship** between input X and output Y.

Basic equation:

```text
ŷ = mx + c
```

Where:

```text
ŷ = Predicted value
x = Input feature
m = Slope
c = Intercept
```

Example:

```text
ŷ = 2x + 5
```

If:

```text
x = 10
```

Then:

```text
ŷ = 2(10) + 5
ŷ = 25
```

Prediction = 25

# 6. Slope (m)

## What is Slope?

Slope (`m`) tells us how much the dependent variable (`Y`) changes when the independent variable (`X`) changes by 1 unit.

Linear Regression-এর formula:

```text
m = Σ[(xi − x̄)(yi − ȳ)] / Σ[(xi − x̄)²]
```

Where:

```text
m  = Slope
xi = Individual X value
yi = Individual Y value
x̄ = Mean of X
ȳ = Mean of Y
```

---

## Example

Given:

```text
x = [1000, 1500, 2000]

y = [200, 300, 400]
```

### Step 1: Calculate Mean of X

```text
x̄ = (1000 + 1500 + 2000) / 3

x̄ = 4500 / 3

x̄ = 1500
```

### Step 2: Calculate Mean of Y

```text
ȳ = (200 + 300 + 400) / 3

ȳ = 900 / 3

ȳ = 300
```

### Step 3: Calculate the values

Mean and Deviation Table

xi     yi     xi - x̄             yi - ȳ             (xi - x̄)(yi - ȳ)              (xi - x̄)^2

1000   200    1000-1500=-500     200-300=-100      (-500)(-100)=50,000          (-500)^2=250,000

1500   300    1500-1500=0        300-300=0         (0)(0)=0                     0^2=0

2000   400    2000-1500=500      400-300=100       (500)(100)=50,000            500^2=250,000


Total:

Σ(xi - x̄)(yi - ȳ) = 50,000 + 0 + 50,000
                    = 100,000

Σ(xi - x̄)^2 = 250,000 + 0 + 250,000
              = 500,000

Therefore:

```text
m = 100000 / 500000

m = 0.2
```

So:

```text
Slope = 0.2
```

### Interpretation

For every 1-unit increase in X, the predicted Y increases by approximately **0.2 units**, according to this model.

---

## Python

```python
x = [1000, 1500, 2000]
y = [200, 300, 400]

x_mean = sum(x) / len(x)
y_mean = sum(y) / len(y)

numerator = sum(
    (xi - x_mean) * (yi - y_mean)
    for xi, yi in zip(x, y)
)

denominator = sum(
    (xi - x_mean) ** 2
    for xi in x
)

m = numerator / denominator

print(m)
```

Output:

```text
0.2
```

# 7. Intercept

Intercept is the predicted value of Y when X = 0.

Formula:

```text
c = ȳ - mx̄
```

Using the previous example:

```text
x = [1000, 1500, 2000]

y = [200, 300, 400]

x̄ = 1500
ȳ = 300
m = 0.2
```

Therefore:

```text
c = 300 - (0.2 × 1500)

c = 300 - 300

c = 0
```

So:

```text
Intercept = 0
```

Therefore, the Linear Regression equation is:

```text
ŷ = mx + c

ŷ = 0.2x + 0

ŷ = 0.2x
```

### Interpretation

When:

```text
X = 0
```

the model predicts:

```text
Y = 0
```

The intercept is the point where the regression line crosses the Y-axis.

Python:

```python
m = 0.2
x_mean = 1500
y_mean = 300

c = y_mean - m * x_mean

print(c)
```

Output:

```text
0.0
```

# 9. Residual / Error

Residual is the difference between the actual and predicted values.

Formula:

```text
Residual = y - ŷ
```

Example:

```text
Actual = 100
Predicted = 90
```

Therefore:

```text
Residual = 100 - 90
         = 10
```

Python:

```python
actual = 100
predicted = 90

residual = actual - predicted

print(residual)
```

Output:

```text
10
```

Important:

```text
Positive residual
→ Actual > Predicted

Negative residual
→ Actual < Predicted
```

# 10. Cost Function

Cost Function measures how far predictions are from actual values.

The goal of Linear Regression is:

```text
Minimize Cost
```

A common cost function is MSE.

Formula:

```text
J(m,c) = (1/n) Σ(yᵢ - ŷᵢ)²
```

Example:

```text
Actual:
[10, 20]

Predicted:
[12, 18]
```

Errors:

```text
10 - 12 = -2
20 - 18 = 2
```

Squared errors:

```text
4
4
```

Therefore:

```text
MSE = (4 + 4) / 2
    = 4
```

Cost = 4

---

# 11. MAE — Mean Absolute Error

MAE measures the average absolute error.

Formula:

```text
MAE = (1/n) Σ|yᵢ - ŷᵢ|
```

Example:

```text
Actual:
[10, 20]

Predicted:
[12, 18]
```

Absolute errors:

```text
|10 - 12| = 2
|20 - 18| = 2
```

Therefore:

```text
MAE = (2 + 2) / 2
    = 2
```

MAE = 2

Python:

```python
from sklearn.metrics import mean_absolute_error

y_true = [10, 20]
y_pred = [12, 18]

mae = mean_absolute_error(y_true, y_pred)

print(mae)
```

Output:

```text
2.0
```

Interpretation:

```text
MAE = 0
→ Perfect prediction

Lower MAE
→ Smaller average absolute error
```

---

# 12. MSE — Mean Squared Error

Formula:

```text
MSE = (1/n) Σ(yᵢ - ŷᵢ)²
```

Example:

```text
Actual:
[10, 20]

Predicted:
[12, 18]
```

Errors:

```text
[-2, 2]
```

Squared errors:

```text
[4, 4]
```

MSE:

```text
MSE = (4 + 4) / 2
    = 4
```

Python:

```python
from sklearn.metrics import mean_squared_error

y_true = [10, 20]
y_pred = [12, 18]

mse = mean_squared_error(y_true, y_pred)

print(mse)
```

Output:

```text
4.0
```

Important:

```text
MSE penalizes large errors more heavily
because the errors are squared.
```

Formula:

```text

```

Example:

```text

RMSE = √4

```


# 14. R² Score — Coefficient of Determination

R² measures how much variation in the target is explained by the model relative to a mean-baseline model.

Formula:

```text
R² = 1 - [Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)²]
```

Example:

```text
Actual:
[10, 20, 30]

Predicted:
[12, 18, 28]
```

Mean:

```text
ȳ = (10 + 20 + 30) / 3
  = 20
```

SSE:

```text
(10-12)² + (20-18)² + (30-28)²

= 4 + 4 + 4

= 12
```

SST:

```text
(10-20)² + (20-20)² + (30-20)²

= 100 + 0 + 100

= 200
```

Therefore:

```text
R² = 1 - (12 / 200)

   = 1 - 0.06

   = 0.94
```

R² = 0.94

Interpretation:

```text
R² = 1
→ Perfect fit

R² = 0
→ Same performance as predicting the mean
  on that evaluation set

R² < 0
→ Worse than predicting the mean
```

Important:

```text
R² can be negative.
```

Python:

```python
from sklearn.metrics import r2_score

y_true = [10, 20, 30]
y_pred = [12, 18, 28]

r2 = r2_score(y_true, y_pred)

print(r2)
```

Output:

```text
0.94
```

# 21. Vector Form

Multiple Linear Regression can be represented as:

```text
Y = Xβ + ε
```

Where:

```text
Y = Target vector
X = Feature matrix
β = Coefficient vector
ε = Error vector
```

Example:

```text
Y =
[200
 300
 400]
```

Feature matrix including an intercept column:

```text
X =
[1000 1
 1500 1
 2000 1]
```

Coefficient vector:

```text
β =
[0.2
 0]
```

Then:

```text
1000(0.2) + 1(0) = 200

1500(0.2) + 1(0) = 300

2000(0.2) + 1(0) = 400
```

Therefore:

```text
Y = Xβ
```

# 22. Normal Equation

Normal Equation directly calculates the coefficients for Ordinary Least Squares.

Formula:

```text
β = (XᵀX)⁻¹Xᵀy
```

Here X normally includes a column for the intercept.

Example:

```text
X =
[1 1
 1 2
 1 3]
```

```text
y =
[2
 4
 6]
```

Result:

```text
β =
[0
 2]
```

Therefore:

```text
y = 0 + 2x

y = 2x
```

Advantages:

• No learning rate
• No iterative updates

Disadvantages:

• Computational cost can become high with many features
• Direct matrix inversion is not numerically ideal; practical implementations often use more stable linear algebra methods

Important:

```text
(XᵀX)⁻¹
```

requires the matrix to be invertible. If it is singular, a pseudoinverse or another numerical method can be used.

# 23. Gradient Descent

Gradient Descent is an iterative optimization algorithm.

Goal:

```text
Minimize Cost Function
```

For parameters m and c:

```text
m = m - α(∂J/∂m)

c = c - α(∂J/∂c)
```

Where:

```text
α = Learning Rate
```

Example:

```text
Current m = 1

Gradient = 4
Learning Rate = 0.1
```

Then:

```text
New m = 1 - 0.1(4)

      = 0.6
```

The parameter moves in the direction that reduces the cost.

---

# 24. Learning Rate

Learning Rate controls the size of each update.

Example:

```text
Learning Rate = 0.01
```

Small update.

Large learning rate:

```text
0.9
```

May overshoot the minimum or make optimization unstable.

Very small learning rate:

```text
0.000001
```

May converge very slowly.

# 25. Partial Derivative

MSE:

```text
J(m,c) = (1/n)Σ(yᵢ - ŷᵢ)²
```

Since:

```text
ŷᵢ = mxᵢ + c
```

Derivative with respect to m:

```text
∂J/∂m = -(2/n)Σxᵢ(yᵢ - ŷᵢ)
```

Derivative with respect to c:

```text
∂J/∂c = -(2/n)Σ(yᵢ - ŷᵢ)
```

Why `2`?

Because:

```text
d(x²)/dx = 2x
```

Why negative sign?

Because:

```text
d(y - mx - c)/dm = -x
```

# 26. Feature Scaling

Feature Scaling puts features into comparable numerical ranges.

Two common methods:

```text
Standardization
Min-Max Scaling
```

Example:

```text
Age = 25
Salary = 500000
```

The scales are very different.

Scaling is especially useful for optimization-based models such as:

```text
SGDRegressor
PassiveAggressiveRegressor
```

and is generally important for regularized models such as:

```text
Ridge
Lasso
ElasticNet
```

Tree-based models usually do not require feature scaling.

---

# 27. Standardization

Formula:

```text
z = (x - μ) / σ
```

Where:

```text
μ = Mean
σ = Standard Deviation
```

Python:

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

Important:

```text
fit_transform()
→ Training data

transform()
→ Test data
```

Never fit the scaler separately on the test set.

---

# 28. Min-Max Scaling

Formula:

```text
x' = (x - min(x)) / (max(x) - min(x))
```

Example:

```text
x = 50
min = 0
max = 100
```

Therefore:

```text
x' = (50 - 0) / (100 - 0)

   = 0.5
```

Python:

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

Important:

```text
Fit only on training data.
```

# 30. Underfitting

Underfitting occurs when a model is too simple to capture the underlying pattern.

Example:

```text
Actual relationship = Curve

Model = Straight line
```

Symptoms:

```text
Training Error → High
Testing Error  → High
```

Solutions:

• Add useful features
• Increase model complexity appropriately
• Reduce excessive regularization

---

# 31. Overfitting

Overfitting occurs when a model learns the training data too closely, including noise.

Symptoms:

```text
Training Error → Very Low
Testing Error  → High
```

Solutions:

• Regularization
• More training data
• Cross Validation
• Feature selection
• Reduce model complexity

# 33. Cross Validation

Cross Validation evaluates a model across multiple train-validation splits.

K-Fold Example:

```text
Dataset
   ↓
Fold 1
Fold 2
Fold 3
Fold 4
Fold 5
```

Each fold becomes validation data once.

Python:

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(
    model,
    X,
    y,
    cv=5,
    scoring="r2"
)

print(scores)
print(scores.mean())
```

Example output:

```text
[0.82, 0.85, 0.80, 0.84, 0.83]

Mean = 0.828
```

Cross-validation helps estimate how the model may generalize, but it does not replace a final untouched test set when one is needed.

# 34. Regularization

Regularization adds a penalty to the loss function to control model complexity.

Main types:

```text
Ridge
→ L2

Lasso
→ L1

ElasticNet
→ L1 + L2
```

Regularization is commonly used to reduce overfitting and control large coefficients.

---

# 35. Ridge Regression

Ridge uses L2 regularization.

Conceptually:

```text
Loss = MSE + λΣβ²
```

Ridge penalizes large coefficients and usually shrinks them toward zero.

Example:

```text
Original coefficient:

β = 10

Squared penalty term:

10² = 100
```

Python:

```python
from sklearn.linear_model import Ridge

model = Ridge(alpha=1.0)

model.fit(X_train, y_train)
```

`alpha` controls regularization strength.

Interpretation:

```text
Higher alpha
→ Stronger regularization

Lower alpha
→ Weaker regularization
```

---

# 36. Lasso Regression

Lasso uses L1 regularization.

Formula:

```text
Loss = MSE + λΣ|β|
```

Example:

```text
β₁ = 10
β₂ = 0.2
β₃ = 0
```

Lasso can make some coefficients exactly zero.

Therefore Lasso can perform:

```text
Feature Selection
```

Python:

```python
from sklearn.linear_model import Lasso

model = Lasso(alpha=1.0)

model.fit(X_train, y_train)
```

---

# 37. ElasticNet

ElasticNet combines L1 and L2 regularization.

Conceptually:

```text
Loss =
MSE
+ L1 penalty
+ L2 penalty
```

Python:

```python
from sklearn.linear_model import ElasticNet

model = ElasticNet(
    alpha=1.0,
    l1_ratio=0.5
)

model.fit(X_train, y_train)
```

`l1_ratio` controls the mixture between L1 and L2.

Conceptually:

```text
l1_ratio = 1
→ L1 component only

l1_ratio = 0
→ L2 component only
```

---

# 40. Grid Search

GridSearchCV searches through specified hyperparameter combinations using cross-validation.

Example:

```python
from sklearn.model_selection import GridSearchCV
from sklearn.linear_model import Ridge

params = {
    "alpha": [0.01, 0.1, 1, 10, 100]
}

grid = GridSearchCV(
    Ridge(),
    params,
    cv=5,
    scoring="r2"
)

grid.fit(X_train, y_train)

print(grid.best_params_)
```

Example output:

```text
{'alpha': 10}
```

Important:

```text
The selected parameter depends on the data,
CV strategy, and scoring metric.
```

---

# 41. Randomized Search

RandomizedSearchCV samples a specified number of hyperparameter combinations instead of evaluating every possible combination.

Useful when there are many hyperparameters or very large search spaces.

```python
from sklearn.model_selection import RandomizedSearchCV
from sklearn.linear_model import Ridge

params = {
    "alpha": [0.01, 0.1, 1, 10, 100]
}

search = RandomizedSearchCV(
    Ridge(),
    params,
    n_iter=5,
    cv=5,
    scoring="r2",
    random_state=42
)

search.fit(X_train, y_train)
```

# 43. Huber Regressor

HuberRegressor is a robust regression model.

It is less sensitive to outliers than ordinary least-squares regression because it uses a loss function that behaves differently for large residuals.

Example:

```text
Data:

10
20
30
40
1000
```

`1000` is an extreme observation.

Ordinary Linear Regression can be strongly affected by it.

Huber Regression reduces the influence of large residuals.

Python:

```python
from sklearn.linear_model import HuberRegressor

model = HuberRegressor()

model.fit(X_train, y_train)
```

# 44. RANSAC Regressor

RANSAC means:

```text
Random Sample Consensus
```

It repeatedly fits a model to subsets of data and tries to find a model supported by a large group of observations.

Observations that do not fit the consensus model can be treated as outliers.

Example:

```text
Normal points:

10
20
30
40

Outlier:

500
```

RANSAC can identify observations that are inconsistent with the main model.

Python:

```python
from sklearn.linear_model import RANSACRegressor

model = RANSACRegressor()

model.fit(X_train, y_train)
```

# 45. Theil-Sen Regressor

Theil-Sen is a robust regression method.

```python
from sklearn.linear_model import TheilSenRegressor
```

# 46. SGDRegressor

• Large datasets
• Online learning
• Incremental learning

```python
from sklearn.linear_model import SGDRegressor
```

# 53. Linear Regression Assumptions

Important classical assumptions include:

```text
1. Linearity
2. Independence
3. Homoscedasticity
4. Appropriate residual distribution
5. No severe multicollinearity
```

These assumptions matter particularly for:

```text
Coefficient interpretation
Statistical inference
Confidence intervals
Hypothesis testing
```

For prediction, model performance should also be evaluated empirically on appropriate validation/test data.

---

# 54. Linearity

The relationship between predictors and the expected target should be appropriately modeled as linear in the model parameters.

Example:

```text
X increases
Y approximately follows a straight-line relationship
```

If the relationship is strongly curved:

```text
Polynomial features
Transformations
or another model
```

may be appropriate.

---

# 55. Independence

Observations/errors should be appropriately independent for classical regression assumptions.

Example:

```text
Student A
Student B
Student C
```

If observations are repeated measurements from the same person, independence may not hold.

Time-series data can also violate independence because nearby observations may be correlated.

---

# 56. Homoscedasticity

Homoscedasticity means the residual variance is approximately constant across fitted values.

Good pattern:

```text
Residual spread:
small
medium
small
medium
```

Problem:

```text
small spread → large spread
```

The second pattern is called:

```text
Heteroscedasticity
```

---

# 57. Normality of Residuals

For classical statistical inference, residuals are often assumed to be approximately normally distributed.

Important:

```text
The target variable itself does not necessarily need
to be normally distributed.
```

Residual diagnostics are more relevant.

---

# 58. Multicollinearity

Multicollinearity occurs when predictor variables are highly correlated.

Example:

```text
House Size
Number of Rooms
Number of Bedrooms
```

These variables may contain overlapping information.

Problems:

• Coefficients can become unstable
• Standard errors can increase
• Coefficient interpretation becomes difficult

---

# 59. VIF — Variance Inflation Factor

VIF can be used to diagnose multicollinearity.

General interpretation:

```text
Low VIF
→ Less evidence of problematic multicollinearity

High VIF
→ More evidence of multicollinearity
```

Common Python:

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor

for i in range(X.shape[1]):
    print(
        variance_inflation_factor(X.values, i)
    )
```

There is no single universal cutoff that applies to every dataset.

Values such as:

```text
5
10
```

are commonly used as rules of thumb, but context matters.

---

# 60. Outliers

An outlier is an observation that is unusually far from the general pattern.

Example:

```text
Salary:

30000
32000
35000
34000
500000
```

`500000` may be an outlier depending on the context.

Possible approaches:

• Investigate the data
• Correct data errors
• Transform variables
• Use robust regression
• Remove observations only when justified

Important:

```text
An outlier is not automatically a bad data point.
```

---

Concept:

# 64. Adjusted R²

Regular R² can increase or remain unchanged when additional predictors are added.

Adjusted R² accounts for the number of predictors.

Formula:

```text
Adjusted R² =
1 - [(1 - R²)(n - 1) / (n - p - 1)]
```

Where:

```text
n = Number of observations
p = Number of predictors
```

Example:

```text
R² = 0.90
n = 100
p = 5
```

Then:

```text
Adjusted R²
= 1 - [(1 - 0.90)(99)/(94)]

= 1 - [0.1 × 99 / 94]

= 1 - 9.9 / 94

≈ 1 - 0.105319

≈ 0.894681
```

Therefore:

```text
R² ≈ 0.90

Adjusted R² ≈ 0.895
```

---

# 65. Confidence Interval

A Confidence Interval represents uncertainty about a population/model parameter.

Example:

```text
Coefficient = 5.2

95% Confidence Interval:
[4.8, 5.6]
```

This is about uncertainty in the estimated parameter, not the range of individual future observations.

---

# 66. Prediction Interval

Prediction Interval represents uncertainty around an individual future observation.

Example:

```text
Predicted salary = 50000

Prediction Interval:
[45000, 55000]
```

Prediction intervals are generally wider than confidence intervals because they include:

```text
Parameter uncertainty
+
Individual outcome variability
```

# 67. Log Transformation

Log transformation can help with strongly skewed variables or multiplicative relationships.

Example:

```python
import numpy as np

y_log = np.log1p(y)
```

After prediction:

```python
y_pred_original = np.expm1(y_pred_log)
```

Example:

```text
Original:
[10, 100, 1000, 10000]

Log transformed:
Much more compressed scale
```

Important:

```text
When transforming the target, evaluate predictions
appropriately after inverse transformation if the metric
is intended to be interpreted on the original scale.
```

---

# 68. Data Leakage

Data Leakage happens when information that should not be available during prediction is accidentally used during training.

Bad example:

```text
Use future information
↓
Train model
↓
Excellent test score
```

But the model will not have that future information in real use.

Another common example:

```text
Fit scaler on the entire dataset
before train-test split
```

This allows information from the test set to influence preprocessing.

Correct:

```python
scaler.fit(X_train)

X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

Better approach:

```text
Use Pipeline
```

for preprocessing and model training.

---

# 69. Pipeline

Pipeline combines preprocessing and model training.

Example:

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("model", Ridge(alpha=1.0))
])

pipeline.fit(X_train, y_train)

y_pred = pipeline.predict(X_test)
```

Advantages:

• Prevents preprocessing mistakes
• Helps prevent data leakage
• Makes workflow cleaner
• Works well with cross-validation
• Works well with hyperparameter tuning

# 70. Model Evaluation

Python:

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

mae = mean_absolute_error(y_test, y_pred)

mse = mean_squared_error(y_test, y_pred)

rmse = mse ** 0.5

r2 = r2_score(y_test, y_pred)

print("MAE:", mae)
print("MSE:", mse)
print("RMSE:", rmse)
print("R2:", r2)
```

Example:

```text
MAE  = 10
MSE  = 150
RMSE = 12.25
R²   = 0.90
```

Remember:

```text
For MAE/MSE/RMSE:
Lower is generally better.

For R²:
Higher is generally better for the same evaluation setup.
```

---

# 71. MAE vs MSE vs RMSE vs R²

```text
MAE
→ Average absolute error
→ Easy to interpret
→ Less sensitive to outliers than MSE

MSE
→ Average squared error
→ Strongly penalizes large errors

RMSE
→ Square root of MSE
→ Same unit as target

R²
→ Measures performance relative to a mean-baseline
→ Scale-free
```

---

# 72. MAPE

Formula:

```text
MAPE = (100/n) Σ |(yᵢ - ŷᵢ) / yᵢ|
```

Example:

```text
Actual = 100
Predicted = 90
```

Percentage Error:

```text
|100 - 90| / 100 × 100

= 10%
```

Important:

```text
MAPE is undefined when actual = 0.

It can also behave poorly when actual values
are very close to zero.
```

---

# 73. MSLE

MSLE = Mean Squared Logarithmic Error.

It compares logarithmic differences between actual and predicted values.

Useful when:

```text
Target is non-negative
Relative differences matter
```

Python:

```python
from sklearn.metrics import mean_squared_log_error

msle = mean_squared_log_error(
    y_test,
    y_pred
)
```

Important:

```text
MSLE requires non-negative actual and predicted values.
```
